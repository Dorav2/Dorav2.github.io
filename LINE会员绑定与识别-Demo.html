H5 与 LINE 登录/注册流程

三种入口共用同一套 CRM 会员底座，但身份获取与绑定路径不同。
01普通 H5 登录/注册
打开会员 H5桌码 / 会员注册码 / 外部链接
→
手机号＋验证码同一页面完成验证
→
CRM 查询手机号判断是否已有会员
手机号判断结果
已有会员
登录成功 → 进入会员中心
新用户
填写会员资料 → 创建会员 → 进入会员中心
该流程只建立 CRM 会员身份，不会自动建立 LINE 绑定关系。
02H5 使用 LINE 授权登录/注册
会员 H5 登录页点击 Login with LINE
→
LINE 官方授权获取 LINE User ID
→
返回会员 H5手机号＋验证码
CRM 查询手机号
已有会员
关联 LINE 身份 → 进入会员中心
新用户
填写会员资料 → 创建会员并关联 LINE → 进入会员中心
LINE 授权用于取得身份，不代表已经关注商户 OA；未关注时仍需引导添加好友。
03LINE Rich Menu 登录/注册
点击 Rich Menu进入会员中心入口
→
打开 LIFF获取 LINE User ID
→
CRM 查询绑定关系LINE 身份是否已关联会员
LINE 绑定判断结果
已绑定会员
免输入 → 直接进入会员中心
未绑定
手机号＋验证码 → 已有会员：建立绑定 / 新用户：填写资料并创建会员 → 进入会员中心
从 Rich Menu 进入时顾客已经是 OA 好友；完成绑定后可使用 LINE 身份免登录进入。
视觉与组件沿用我方现有规范：C 端按 Figma《V 2.16 个人中心》（375×812、页面底 #F0F2F4、卡片白底圆角、品牌橙主按钮、C 端按钮统一胶囊形状、状态图标带图例），后台按 GPOS_Web 规范（1、表格页 / pageheader / 表格_输入类 / 3、详情页，后台按钮保持规范方形，不与 C 端互套）。 渠道品牌色（LINE 绿）仅用于描边按钮与浅底卡片，不作大面积实心按钮；按钮文案均带动作对象。 顾客可先手机号入会后从会员首页 Add LINE，也可在登录页直接 Login with LINE。P0 支持顾客通过手机号 OTP 自助解绑；发生手机号绑定冲突时，可验证身份后完成换绑。
